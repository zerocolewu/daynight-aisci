================================================================================
ROOT CAUSE ANALYSIS
================================================================================

Primary Issue: Missing Learning Rate Schedule
----------------------------------------------
Paper says "Chemprop default hyperparameters" but doesn't explicitly mention
that Chemprop uses a NOAM learning rate schedule:

  - Warmup: 2 epochs (LR increases from init_lr to max_lr)
  - Decay: Cosine decay from max_lr to final_lr
  - This helps escape local minima and converge better

Evidence:
  - Training curves show models still improving at epoch 50
  - Validation RMSE varied significantly (44-53 across folds)
  - Better optimization could easily improve 5-10 RMSE

Secondary Issues:
-----------------
  - Data preprocessing (1-2 RMSE): Missing median aggregation
  - Implementation details (1-2 RMSE): Not using actual Chemprop package
  - Dataset differences (1-2 RMSE): 7170 vs 7235 samples
