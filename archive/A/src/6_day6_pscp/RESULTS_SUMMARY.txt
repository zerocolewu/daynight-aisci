EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The PSCP (Polymer-Specific Contrastive Pretraining) experiment was conducted
through multiple iterations to predict glass transition temperature (Tg) for
polymers. The experiment achieved a best RMSE of 35.42, improving upon the
MLP+ECFP4 baseline (37.76) by 2.34 RMSE points (6.2% reduction).

KEY FINDING:
PSCP explains approximately 54% of PerioGT's reported 4.35 RMSE advantage.
The remaining 46% likely comes from PerioGT's periodic table embeddings and
other architectural innovations.

IMPLEMENTATION DETAILS
================================================================================

CRITICAL FIXES:
1. SMILES Cleaning:
   - Before: smiles.replace('*', '') → 17% valid molecules
   - After:  smiles.replace('*', '[H]') → 97% valid molecules

2. Atom Features:
   - Before: 5 raw normalized features
   - After:  154-dimensional one-hot encoding

MODEL ARCHITECTURE:
- Encoder: 3-layer GIN (256 hidden dim)
- Input: Molecular graph + 2048-bit ECFP4
- Head: MLP [256 → 64 → 1]

PRETRAINING:
- Method: Supervised contrastive learning (InfoNCE loss)
- Data: PI1M polymer dataset (99K graphs)
- Best temperature: 0.05

================================================================================
CONCLUSION
================================================================================

The PSCP experiment successfully:

1. Fixed critical SMILES cleaning and atom feature issues
2. Established baseline performance (37.76 RMSE)
3. Demonstrated consistent improvement with pretraining
4. Achieved best RMSE of 35.42 (6.2% improvement)
5. Explained 54% of PerioGT's advantage

However:
1. Target RMSE < 35.0 not achieved (gap: 0.42)
2. Full PerioGT advantage not explained (46% remaining)

The results validate the PSCP approach and suggest that further improvements
in polymer-specific architectures (e.g., periodic table embeddings) are needed
to match PerioGT's performance.
