FINDING 1: Contrastive Learning Provides Minimal Benefit
---------------------------------------------------------
The supervised-only baseline achieves competitive performance (41.59 RMSE)
compared to full FGCL (41.65 RMSE). The difference is NOT statistically
significant given the standard deviations.

Conclusion: ECFP-based contrastive learning does NOT explain performance gains.

FINDING 2: Supervised Baseline is Very Strong
----------------------------------------------
GIN + ECFP concatenation alone achieves R² = 0.862 with low variance (σ = 1.06).
This suggests the architectural choice (GIN + ECFP features) is the key factor,
not the contrastive learning objective.

FINDING 3: Pre-training May Be Detrimental
-------------------------------------------
The "pretrain_only" condition shows:
- Highest variance (σ = 2.33)
- Slightly worse average performance (42.09 RMSE)
- Inconsistent benefits across folds

This suggests contrastive pre-training doesn't transfer well to this regression task.

FINDING 4: Lambda Weight Insensitivity
---------------------------------------
Performance is relatively stable across λ ∈ {0.1, 0.5, 1.0, 2.0}:
- Range: 41.59 - 41.76 RMSE (very narrow)
- No clear optimal λ value
- Suggests contrastive loss has minimal impact

================================================================================
6. SCIENTIFIC CONCLUSIONS
================================================================================

PRIMARY CONCLUSION:
-------------------
ECFP-based contrastive learning does NOT provide significant benefits for
Tg (glass transition temperature) prediction in polymers.

The hypothesis that PerioGT's performance advantage comes from contrastive
representation learning is NOT supported by this experiment.

IMPLICATIONS:
-------------
1. For molecular property prediction with sufficient labeled data (~7K samples),
   contrastive pre-training may not be necessary.

2. The computational overhead of contrastive learning (pre-training + additional
   loss computation) is NOT justified for this task.

3. The GIN architecture + ECFP feature combination is already powerful enough
   for this regression task.

4. Future work should focus on:
   - Architecture improvements (attention mechanisms, better pooling)
   - Better feature engineering (beyond ECFP)
   - Data augmentation strategies
   - Rather than contrastive learning objectives

RECOMMENDATIONS:
----------------
1. Use standard supervised GIN + ECFP for Tg prediction (simplest, most stable)
2. Skip contrastive pre-training for regression tasks with adequate data
3. Consider contrastive learning only for:
   - Low-data regimes (<1000 samples)
   - Transfer learning scenarios
   - Different molecular properties where structural similarity matters more
